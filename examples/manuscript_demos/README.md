# Historical Two-Route Demos

The October 1 demos used the old Laplace API and a historical Python GHQ
implementation. Their coupled source/data bundle has been removed from the
current tree; the complete snapshot remains at `manuscript-20261018`.

For current reference and sensitivity calculations, use
[the current examples](../README.md). For historical reproduction, follow
[the separate-checkout instructions](../../docs/migration.md#historical-october-18-snapshot)
and the README in that checkout. Do not mix historical sources with the
current 0.2.0 package.
